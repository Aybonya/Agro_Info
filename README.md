# Agro_Info

## Задание 2. Техника и государственные номера

Нормальная рабочая модель: пайплайн для набора фото с весовой (`data/Auto`) —
находит технику на кадре, распознаёт государственный номер (если он виден и
читается), определяет тип техники и производителя, сохраняет результат в
JSON/CSV и размечает все обработанные кадры для демонстрации.

### Как это работает

1. **Детекция техники** — `YOLOv8n` (предобученная на COCO) находит на кадре
   объект класса car/truck/bus и берёт самый крупный по площади бокс. Если на
   основном разрешении (1280px) технику не нашли или спутали с посторонним
   классом (например, вытянутый грузовик распознаётся как "train") — детекция
   повторяется на 640px, а затем на 640px с более мягким порогом уверенности
   (для нестандартной техники вроде тракторов, которой нет среди классов COCO).
2. **Номер** — `PaddleOCR` (PP-OCRv4) читает текст в области техники, из
   распознанных фрагментов выбирается тот, что соответствует формату
   казахстанского номера: однострочному (3 цифры + 1–3 буквы + 2 цифры
   региона, например `160ALV10`) или старому двухстрочному (буквенная серия
   сверху, номер снизу, например `AFE`/`P523`). Если табличка слишком мелкая
   в кадре — область номера дополнительно ищется повторно на увеличенном
   кропе нижней части техники. Если текст так и не сложился в номер, но рядом
   найдена компактная (1–2 фрагмента) уверенно прочитанная область с цифрами —
   она всё равно отмечается как вероятное место номера, просто без
   подтверждённого текста (см. ниже про `unknown_*`). Найденная область
   вырезается и сохраняется отдельным файлом в `results/plates/`.
3. **Тип техники** — zero-shot классификация `CLIP (ViT-B/32)`: кроп техники
   сравнивается с текстовыми описаниями (самосвал, бортовой/зерновоз,
   автоцистерна, трактор, легковой, автобус, спецтехника).
4. **Производитель** — сначала ищем название бренда (KAMAZ, MAZ, GAZ, VOLVO...)
   в тексте, который OCR прочитал на решётке/кузове (нечёткое сравнение).
   Если текста нет или бренд не распознан — используется zero-shot CLIP по
   списку известных производителей.

Модель техники (конкретная модельная линейка, напр. КАМАЗ-5320) в общем
случае надёжно не определяется без отдельно размеченного датасета и
обученного классификатора — в этой версии не выводится, чтобы не давать
случайные значения.

### Установка и запуск

Нужен Python 3.11 (в 3.14 часть ML-пакетов ещё не имеет колёс на Windows).

```bash
python -m venv .venv
.venv\Scripts\activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python src/pipeline.py
```

Torch ставится отдельной командой с CPU-индексом — иначе pip по умолчанию
тянет CUDA-сборку (~2.5 ГБ) вместо CPU-версии (~120 МБ).

Фото для обработки должны лежать в `data/Auto/*.jpg`. По умолчанию
обрабатываются все фото из этой папки, но можно указать конкретные файлы или
другую папку:

```bash
python src/pipeline.py                  # все фото из data/Auto
python src/pipeline.py 5.jpg 12.jpg      # только эти два файла
python src/pipeline.py --dir другая_папка # все фото из другой папки
```

При обработке отдельных файлов (не всей папки) результаты по остальным ранее
обработанным фото не теряются — `results.json`/`results.csv` обновляются
точечно, только по указанным файлам.

При первом запуске автоматически скачаются веса `yolov8n.pt`, веса CLIP и
модели PaddleOCR — нужен интернет, дальше всё работает офлайн.

### Результат

- `results/results.json`, `results/results.csv` — по каждому фото: файл,
  найдена ли техника, тип техники (RU), производитель, номер, координаты
  бокса, confidence-оценки.
- `results/annotated/` — все обработанные кадры с отрисованными боксами
  техники и номера для демонстрации.
- `results/plates/` — чистый кроп (без рамок/подписей) области номера,
  отдельным файлом `<номер>_<фото>.jpg`. Если текст распознать не удалось, но
  граница таблички видна (например, она слишком мелкая или размытая) — кроп
  всё равно сохраняется, с именем `unknown_<фото>.jpg`.

### Известные ограничения

- Номер распознаётся только если видна лицевая/задняя часть техники с
  читаемой табличкой — на ракурсах сбоку/издали текст может не найтись.
- Поддерживается только казахстанский формат номера (однострочный и старый
  двухстрочный). Номера других стран (например, российский формат
  "буква-3цифры-буква + регион") не распознаются.
- Производитель по CLIP — эвристика, не обученный классификатор; наиболее
  надёжен, когда название бренда физически написано на кузове/решётке.
- Модель техники (конкретная модификация) не выводится — см. выше.
