# Agro_Info

## Задание 2. Техника и государственные номера

Пайплайн для набора фото с весовой (`data/Auto`): находит технику на кадре,
распознаёт государственный номер (если он виден и читается), определяет тип
техники и производителя, сохраняет результат в JSON/CSV и размечает несколько
кадров для демонстрации.

### Как это работает

1. **Детекция техники** — `YOLOv8n` (предобученная на COCO) находит на кадре
   объект класса car/truck/bus и берёт самый крупный по площади бокс.
2. **Номер** — `PaddleOCR` (PP-OCRv4) читает текст в области техники, из
   распознанных фрагментов выбирается тот, что соответствует формату
   казахстанского номера (3 цифры + 1–3 буквы + 2 цифры региона, например
   `160ALV10`). Найденный номер вырезается и сохраняется отдельным файлом в
   `results/plates/`.
3. **Тип техники** — zero-shot классификация `CLIP (ViT-B/32)`: кроп техники
   сравнивается с текстовыми описаниями (самосвал, бортовой/зерновоз,
   автоцистерна, трактор, легковой, автобус, спецтехника).
4. **Производитель** — сначала ищем название бренда (KAMAZ, MAZ, GAZ, VOLVO...)
   в тексте, который OCR прочитал на решётке/кузове (нечёткое сравнение).
   Если текста нет или бренд не распознан — используется zero-shot CLIP по
   списку известных производителей.

Модель техники (конкретная модельная линейка, напр. КАМАЗ-5320) в общем
случае надёжно не определяется без отдельно размеченного датасета и
обученного классификатора — в этой версии не выводится, чтобы не давать
случайные значения.

### Установка и запуск

Нужен Python 3.11 (в 3.14 часть ML-пакетов ещё не имеет колёс на Windows).

```bash
python -m venv .venv
.venv\Scripts\activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python src/pipeline.py
```

Torch ставится отдельной командой с CPU-индексом — иначе pip по умолчанию
тянет CUDA-сборку (~2.5 ГБ) вместо CPU-версии (~120 МБ).

Фото для обработки должны лежать в `data/Auto/*.jpg`.

При первом запуске автоматически скачаются веса `yolov8n.pt`, веса CLIP и
модели PaddleOCR — нужен интернет, дальше всё работает офлайн.

### Результат

- `results/results.json`, `results/results.csv` — по каждому фото: файл,
  найдена ли техника, тип техники (RU), производитель, номер, координаты
  бокса, confidence-оценки.
- `results/annotated/` — несколько кадров с отрисованными боксами техники и
  номера для демонстрации.
- `results/plates/` — чистый кроп (без рамок/подписей) каждого распознанного
  номера, отдельным файлом `<номер>_<фото>.jpg`.

Папка `results/` не хранится в git (это воспроизводимый вывод) — появляется
после запуска `python src/pipeline.py`.

### Известные ограничения

- Номер распознаётся только если видна лицевая/задняя часть техники с
  читаемой табличкой — на ракурсах сбоку/издали текст может не найтись.
- Номера двухстрочного старого образца (текст в две строки на табличке, а не
  в одну) не поддерживаются — распознавание рассчитано на однострочный
  казахстанский формат.
- Производитель по CLIP — эвристика, не обученный классификатор; наиболее
  надёжен, когда название бренда физически написано на кузове/решётке.
- Модель техники (конкретная модификация) не выводится — см. выше.
