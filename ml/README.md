# Модель распознавания техники на весовой

Модель обучается в формате YOLO и сейчас решает одну задачу: на кадре с камеры определить грузовую технику (`gruzovik`) и вернуть её рамку. Она подходит для контроля наличия машины на весовой и дальнейшего запуска распознавания номера.

## Текущий набор

`Auto` содержит 25 исходных кадров с одной камеры. Скрипт `autolabel.py` создаёт первичную разметку, используя предобученную модель, и делит её на train/validation. Авторазметка — стартовая точка: её надо просматривать перед эксплуатацией.

## Запуск

```powershell
cd ml
python autolabel.py
python train.py
python predict.py ..\Auto\1.jpg
```

Итоговая модель: `ml/runs/weighbridge_truck/weights/best.pt`.

## Как добавлять данные

1. Положите новые JPG-файлы в `Auto`.
2. Для первого автоматического наброска рамок запустите `python ml/autolabel.py`.
3. Проверьте и поправьте рамки в `ml/dataset/labels`; формат YOLO: `класс x-центр y-центр ширина высота`, все координаты от 0 до 1.
4. Запустите `python ml/train.py` повторно.

Для разделения по типам техники нужны отдельные классы и размеченные примеры: например `kamaz`, `maz`, `gaz`, `tractor`. Желательно не менее 100 размеченных кадров на класс, включая разные погоду, сезон, освещение, пустую и гружёную машину.
