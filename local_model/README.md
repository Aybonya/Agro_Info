# 💻 Локальная модель детекции (Offline, без интернета)

В этой папке находится всё необходимое для полностью автономной работы на вашем компьютере: обученные нейросети, скрипты инференса и скрипт для дообучения.

---

## Файлы моделей (`weights/`):
* `weights/truck_plate_yolo11n.pt` — единая обученная модель на базе новейшей **YOLO11 Nano**, распознающая грузовики, тракторы, прицепы и номерные знаки;
* `weights/license_plate_yolov8n.pt` — специализированный высокоточный детектор номеров (mAP 99.5%);
* `weights/yolo11n.pt` — базовый детектор транспорта.

---

## Быстрый старт:

### 1. Быстрая проверка на одном фото в консоли:
```powershell
cd local_model
python quick_check.py ../Auto/10.jpg
```

### 2. Полная обработка (детекция грузовика + номера, кроп номера, сохранение размеченного фото):
```powershell
# Обработка одного снимка:
python detect.py ../Auto/10.jpg

# Обработка всей папки снимков:
python detect.py ../Auto/
```

### Режимы работы (`--mode`):
- `--mode pipeline` (по умолчанию) — двухэтапная обработка в сверхвысоком разрешении (1280px). Рекомендуется для камер весовой: уверенность на грузовиках до 87%, на номерах до 79%.
- `--mode unified` — инференс через единую легковесную модель `truck_plate_yolo11n.pt` в один проход.

---

## Структура результатов:
После запуска `python detect.py` результаты сохраняются в папку `output/`:
- `output/annotated/` — фотографии с рамками транспорта и номеров;
- `output/plate_crops/` — вырезанные и увеличенные номерные знаки;
- `output/local_results.json` — отчёт со всеми координатами и вероятностями.

## 🎯 Дообучение модели на новых данных

Для дообучения подготовлена папка `local_model/dataset/`.

### Способ 1. Загрузить новые данные прямо в `local_model/dataset/`:
Разложите новые фотографии и файлы разметки (в формате YOLO `.txt`):
```text
local_model/dataset/
├── data.yaml            <-- конфигурация классов
├── train/
│   ├── images/          <-- фотографии для обучения
│   └── labels/          <-- текстовые файлы разметки
└── valid/
    ├── images/          <-- фотографии для проверки
    └── labels/          <-- текстовые файлы разметки
```
После чего запустите команду:
```powershell
python train.py
```
Скрипт сам обнаружит ваш датасет в `dataset/` и продолжит обучение текущей модели!

### Способ 2. Использовать любой скачанный датасет (например, экспорт из Roboflow):
Если вы скачали ZIP или папку с датасетом из Roboflow (в формате YOLOv8/YOLO11):
```powershell
python train.py --data "C:\путь\к\скачанному\data.yaml" --epochs 50
```

После завершения обучения лучшая модель автоматически сохранится в `weights/truck_plate_yolo11n.pt`, и `detect.py` сразу начнёт использовать обновлённую версию!
