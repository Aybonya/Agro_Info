# ☁️ Детекция через Roboflow Cloud API

В этой папке находится всё необходимое для работы с обученной моделью в облаке **Roboflow**.

## Параметры модели:
- **Проект:** `Trucks Dataset` (workspace `akh-xkhw0`)
- **Версия модели:** `v5` (`trucks-dataset-dqp47/5`)
- **Обучена на:** 582 изображениях техники и номерных знаков
- **Распознаваемые классы:** `truck` (грузовик), `license plate` (номерной знак), `trailer` (прицеп), `tractor` (трактор)
- **Время ответа облака:** ~30–50 мс на изображение

---

## Быстрый старт:

### 1. Установка зависимостей (если ещё не установлены):
```powershell
python -m pip install --ignore-requires-python -r requirements.txt
```

### 2. Быстрая проверка на одном фото (вывод в консоль):
```powershell
cd roboflow_cloud
python quick_check.py ../Auto/10.jpg
```

### 3. Полная обработка фото (с сохранением рамок и кропов номеров):
```powershell
# На одной фотографии:
python detect.py ../Auto/10.jpg

# На всей папке с фото:
python detect.py ../Auto/
```

---

## Структура результатов:
После запуска `python detect.py` результаты сохраняются в папку `output/`:
- `output/annotated/` — фотографии с нанесёнными аккуратными цветными рамками;
- `output/plate_crops/` — автоматически вырезанные номерные знаки для передачи в OCR;
- `output/roboflow_results.json` — машиночитаемый отчёт со всеми координатами и вероятностями.

---

## Настройки:
Ключ API и версия модели задаются в [`config.py`](config.py). При обучении новой версии в Roboflow (например, `v6`) достаточно поменять `MODEL_ID = "trucks-dataset-dqp47/6"`.
